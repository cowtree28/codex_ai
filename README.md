# check

**오늘 할 일을 적고, 진행하고, 돌아보는 개인 일정 관리 앱.**

`check`는 브라우저에서 바로 여는 로컬 웹앱입니다. 날짜가 있는 일정과 날짜 없는 할 일을 함께 관리하고, 진행 상태를 바꾸거나 완료한 일을 기록 화면에서 확인할 수 있습니다.

## 시작하기

설치나 빌드가 필요하지 않습니다. 작업 폴더의 `index.html`을 Chrome 또는 Edge에서 열면 됩니다.

```text
Windows: start index.html
macOS:   open index.html
```

파일을 수정했다면 브라우저를 새로고침하세요. 화면은 `index.html`, 스타일은 `style.css`, 동작은 `app.js`에 있습니다.

## 할 수 있는 일

| 화면 | 기능 |
| --- | --- |
| **오늘** | 일정 추가·수정·삭제, 대기·할 일·진행 중·완료·취소 상태 변경, 목록·그래프 전환 |
| **캘린더** | 월간 일정 확인, 날짜별 일정 열기, 해당 일정 수정·상태 변경·삭제 |
| **기록** | 주간·월간 완료 기록, 날짜별 타임라인과 카테고리별 비율 확인 |
| **설정** | 브라우저 알림 허용, 하루 전·밤 미완료 알림 선택 |

일정을 만들 때 제목과 함께 날짜·시간·메모·카테고리를 적을 수 있습니다. 날짜를 비우면 날짜 없는 할 일로 저장됩니다. 날짜가 있는 일정은 **매일·매주·매월** 반복할 수 있으며, 반복 일정의 상태는 날짜마다 따로 바꿀 수 있습니다. 오늘 화면에는 오늘 일정, 날짜 없는 할 일, 아직 끝나지 않은 지난 일정이 표시됩니다.

## 사용 순서

1. **오늘 → 새 일정**에서 제목을 입력하고 **추가**를 누릅니다. 제목이 비어 있으면 저장되지 않습니다.
2. 일정의 상태 메뉴에서 진행 상태를 바꿉니다. **완료** 또는 **취소**로 바꾸면 제목에 취소선이 표시됩니다.
3. **수정**으로 내용을 고치거나 **삭제**로 일정을 지웁니다. 반복 일정을 삭제할 때는 전체 반복 일정 삭제 여부를 확인합니다.
4. 미래 날짜에 만든 일정은 **캘린더**에서 확인합니다. 완료한 일정은 **기록**에서 날짜와 카테고리별로 볼 수 있습니다.

## 알림과 데이터

**설정 → 알림 허용**에서 브라우저 권한을 허용하면, 브라우저가 열려 있는 동안 매일 오전 8시와 일정 1시간·10분 전에 알림을 확인합니다. 하루 전 오후 8시 알림과 밤 9시 미완료 알림은 설정에서 선택할 수 있습니다. 브라우저나 운영체제가 알림을 제한하면 표시되지 않을 수 있습니다.

일정과 설정은 이 브라우저의 `localStorage`에 저장됩니다. 새로고침해도 남지만, **다른 브라우저·기기와 동기화되지 않으며 브라우저 데이터를 삭제하면 사라질 수 있습니다.** 서버로 데이터를 보내지 않습니다.

## 파일 구성

```text
index.html   화면 구조
style.css    화면 디자인
app.js       일정·반복·기록·알림 동작
AGENTS.md    작업 규칙과 확인 절차
docs/        기획·설계·점검 문서
```

## 직접 확인하기

- 일정 두 개를 추가하고, 하나만 **완료**로 바꾼 뒤 그래프의 건수를 확인합니다.
- 한 일정만 삭제해 다른 일정은 남는지 확인합니다.
- 제목을 비운 채 추가해 안내 문구가 나오는지 확인합니다.
- 새로고침 뒤 일정이 남는지 확인합니다.
- 날짜와 반복을 설정해 캘린더에 표시되는지 확인합니다.
- 개발자 도구 콘솔에 오류가 없는지 확인합니다.
