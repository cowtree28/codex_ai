# 환경 점검

- [ ] VS Code에서 작업 폴더(Windows `C:\work\study-planner` / macOS `~/work/study-planner`)를 열었다 — 확인 방법: VS Code 탐색기 맨 위에 `study-planner` 폴더가 보이는지 확인한다.
- [ ] Codex 확장에 실습 계정으로 로그인했다 — 확인 방법: VS Code의 Codex 확장을 열어 로그인된 계정 표시를 확인한다.
- [ ] 작업 폴더 맨 위에 `AGENTS.md`가 있다 — 확인 방법: VS Code 탐색기에서 `docs` 폴더와 같은 위치의 `AGENTS.md`를 확인한다.
- [ ] 새 대화에서 Codex가 `AGENTS.md` 규칙을 요약했다 — 확인 방법: 새 대화를 열어 규칙 요약을 요청하고 파일 내용과 대조한다.
- [ ] 규칙에 어긋나는 요청(라이브러리 설치)을 Codex가 거절하거나 되물었다 — 확인 방법: 적용할 설치 제한 규칙을 확인한 뒤 실습용 설치 요청에 대한 응답을 확인한다.
- [ ] Codex가 파일을 만들거나 명령을 실행하기 전에 허락을 묻는다 — 확인 방법: 실습용 파일 생성이나 명령 실행을 요청하고 실행 전 허락을 묻는지 확인한다.
- [ ] `docs/plan.md`와 `docs/prompt-design.md`가 있다 — 확인 방법: VS Code 탐색기의 `docs` 폴더에서 두 파일을 확인한다.
- [ ] `git --version`이 동작한다 — 확인 방법: 터미널에서 `git --version`을 실행해 버전 번호가 출력되는지 확인한다.
- [ ] 브라우저(Windows: Chrome 또는 Edge / macOS: Chrome 또는 Safari)가 열린다 — 확인 방법: 해당 브라우저를 실행해 새 탭이 열리는지 확인한다.
- [ ] 코드와 문서에 개인정보 · 비밀번호 · API 키가 없다 — 확인 방법: 작업 폴더의 파일과 변경 내역을 검토해 실제 비밀값이나 개인정보가 없는지 확인한다.
