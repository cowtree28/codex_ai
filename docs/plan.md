## 2. 사용자 (누가 쓰나)

- MVP는 내 PC에서 로컬로만 돌릴거야

## 3. 해결할 문제 (왜 필요한가)
- 내가 일정을 관리할때 일정이 무엇이 있었는지 까먹는 경우가 많은데
- 단순 노트를 사용하거나, linear를 활용할 경우 내 일정을 모두 담지 못하거나 다시 확인을 하는 경우가 많아서
- 그리고 이런 일정을 ai를 이용해 자동으로 기록하고 알림을 많이 띄워서 활용할수 있으면 좋을것같아서

## 4. 기능 목록
### 꼭 필요한 기능 (MVP)
- 일정 조정
  - 일정 CRUD
  - AI 일정 자동 생성 (Gmail, 디스코드 서버 채널에서 뽑아서 바로 등록)
  - 사이클 일정 등록 (반복되는 일정)
- 알림
  - PC 브라우저 알림
- 한 일 정리
  - 언제 뭐했는지 타임라인 그래프로 정리
  - AI가 카테고리 자동 분류, 한마디 요약
### 있으면 좋은 기능 (2차)
- 일정 추천
- 디스코드 유저 앱 (DM 우클릭으로 추가)
- 폰 브라우저 대응 + 폰 알림
- 하루 전 알림, 밤에 미완료 일정 알림

## 5. 화면 구성 (위에서 아래 순서)
### 오늘 화면 (메인)
- 맨 위에 오늘 날짜랑 남은 일정 개수
- "AI가 새로 추가한 일정" 박스: 최근에 자동 등록된 거 보여주고, 틀린 건 바로 수정/삭제
- 오늘 일정 리스트: 시간순으로 보이고, 체크하면 완료 처리
- 직접 추가 버튼
- 왼쪽 사이드바 (오늘 / 캘린더 / 기록 / 설정)
### 캘린더 화면
- 월간 보기
- 날짜 누르면 그날 일정 목록
- 일정 출처 아이콘으로 구분 (직접 / Gmail / 디스코드 / 반복)
### 일정 추가/수정 화면
- 제목, 날짜, 시간, 메모
- 카테고리 (AI가 붙이고, 틀리면 내가 바꿈)
- 반복 설정 (매일 / 매주 / 매월)
### 기록 화면 (한 일 정리)
- 맨 위에 AI 한마디 요약 (ex. "이번주는 회의 5개, 과제 마감 2개 끝냄")
- 날짜별 타임라인 그래프 (카테고리별로 색 다르게)
- 카테고리별 비율 그래프
- 주간/월간 전환
### 설정 화면
- Gmail 연결, 디스코드 봇 연결
- 브라우저 알림 허용

## 6. 사용 흐름 (사용자가 하는 행동 순서)
1. 처음에 설정에서 Gmail 연결하고, 디스코드 봇을 내 서버에 초대하고, 브라우저 알림 허용
2. AI가 주기적으로 Gmail이랑 디스코드 서버 채널 읽어서 일정 있으면 바로 등록
3. 디스코드 DM에 일정 얘기 나오면 봇 있는 채널로 전달
4. 새 일정 등록되면 알림 옴
5. 틀리게 들어간 거 있으면 오늘 화면에서 바로 수정/삭제
6. 따로 생각난 일정은 직접 추가
7. 반복 일정은 한 번 등록해두면 알아서 계속 생김
8. 아침에 오늘 일정 요약 알림 받고, 일정 전에도 알림 받음
9. 끝낸 일은 체크
10. 주말이나 월말에 기록 화면에서 요약이랑 그래프 보면서 돌아봄

### 알림 기본값
- 매일 아침 8시: 오늘 일정 요약
- 일정 1시간 전
- 일정 10분 전
- AI가 새 일정 등록했을 때

## 7. 만들지 않을 것
- 배포, 도메인, 서버 운영 (로컬에서만 돌림)
- 회원가입/로그인
- 폰 화면 대응, 폰 알림, 네이티브 앱
- 디스코드 유저 앱, 셀프봇
- Gmail, 디스코드 말고 다른 연동 (카톡, 구글 캘린더 등)
- 다른 사람이랑 일정 공유/협업
- Linear처럼 이슈/팀/프로젝트 관리하는 기능
- 음성 입력
- 카테고리 직접 만들고 관리하는 기능
- 일정 추천

## 8. 완료 기준
- 일정 추가/조회/수정/삭제가 다 제대로 됨
- Gmail이랑 디스코드 서버 채널에서 일정 들어간 메시지 10개 넣어보면 AI가 9개 이상 날짜/시간 맞게 등록함
- 일정 아닌 메시지를 일정으로 잘못 등록하는 게 거의 없음
- 같은 일정이 여러 군데 있어도 한 번만 등록됨
- 반복 일정 등록하면 해당 날짜마다 제대로 뜸
- PC 브라우저에서 알림이 정해진 시간에 옴 (브라우저 켜져 있을 때 기준)
- 기록 화면에서 언제 뭐했는지 한눈에 보이고, AI 요약이랑 카테고리가 대부분 맞음
- 1~2주 동안 실제로 써보면서 일정 까먹는 일이 줄었으면 MVP 완료
