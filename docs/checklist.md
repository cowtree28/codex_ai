## 회귀 점검표

| 번호 | 항목 | 이렇게 확인한다 | 통과 조건 | 결과 |
| --- | --- | --- | --- | --- |
| 1 | 콘솔 오류 없음 | `npm run build`가 성공하는지 확인한 뒤 `npm run dev`를 실행하고 `http://localhost:3000`을 연다. 개발자 도구 콘솔을 비운 뒤 오늘·캘린더·기록·설정을 차례로 열고 오늘로 돌아온다. | 빌드가 성공하고 각 화면이 표시되며 콘솔에 빨간 오류가 없다. | |
| 2 | ① 추가 | 오늘 화면에서 제목에 `수학 문제집 3쪽`을 입력하고 추가를 누른다. | 일정 목록에 해당 제목이 한 번 나타난다. | |
| 3 | ② 완료 표시(다시 누르면 해제) | `수학 문제집 3쪽`의 상태 메뉴에서 `완료`를 선택한다. 같은 상태 메뉴를 다시 열어 `대기`를 선택한다. | 완료 시 취소선과 흐린 색이 보이고, 대기로 되돌리면 두 표시가 사라진다. | |
| 4 | ③ 가운데 일정 삭제 | 사이트 저장 데이터를 비운 뒤 `수학 문제집 3쪽`, `영어 단어 10개`, `치과 예약`을 이 순서로 추가한다. 가운데 `영어 단어 10개`의 삭제를 누른다. | 가운데 일정만 사라지고 첫째와 셋째 일정은 순서대로 남는다. | |
| 5 | 빈 목록 안내 | 사이트 저장 데이터를 비우고 오늘 화면을 새로고침한다. | 일정 목록에 `일정 없음` 안내가 보인다. | |
| 6 | ④-1 빈 제목 | 사이트 저장 데이터를 비우고 제목 입력칸을 비운 채 추가를 누른다. | `일정 제목을 입력해 주세요.` 안내가 나오고 목록은 빈 상태다. | |
| 7 | ④-2 공백만 입력 | 사이트 저장 데이터를 비우고 제목에 스페이스 세 칸만 넣어 추가를 누른다. | `일정 제목을 입력해 주세요.` 안내가 나오고 목록은 빈 상태다. | |
| 8 | ④-3 정상 제목 | 사이트 저장 데이터를 비우고 `수학 문제집 3쪽`을 입력해 추가를 누른다. | 안내가 사라지고 공백이 없는 제목이 목록에 한 번 나타난다. | |
| 9 | ⑤-1 추가 유지 | 사이트 저장 데이터를 비우고 `수학 문제집 3쪽`, `치과 예약`을 순서대로 추가한 뒤 새로고침한다. | 두 일정이 같은 제목과 순서로 남아 있다. | |
| 10 | ⑤-2 완료·삭제 유지 | 사이트 저장 데이터를 비우고 `수학 문제집 3쪽`, `영어 단어 10개`, `치과 예약`을 순서대로 추가한다. 첫째를 완료로 바꾸고 둘째를 삭제한 뒤 새로고침한다. | 첫째는 완료 표시로, 셋째는 그대로 남고 둘째는 다시 나타나지 않는다. | |
| 11 | ⑤-3 창 다시 열기 | 10번을 마친 브라우저의 해당 탭을 닫고, 같은 브라우저에서 `http://localhost:3000`을 새 탭으로 다시 연다. | 10번의 두 일정과 완료·삭제 상태가 그대로 보인다. | |
